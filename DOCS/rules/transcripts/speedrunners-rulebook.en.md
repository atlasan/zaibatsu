Counters

Control markers

Control counters ( ) indicate the control each player has over the
Cybernet.

At the beginning of the game each player starts with a limited number
of control counters. This number varies depending on the number of
player in the game (see Starting the Game p.07).

Some effects can remove control counters from the Cybernet.

If a player gains control of something that has another player’s control
counters, those control counters are removed.

When a control counter is removed in this way, it is returned to its
owner.

The game ends as soon as a player manages to place all of his control
counters in the Cybernet.

Bonus counters

Bonus counters ( ) represent additional rewards
gained from controlling blocks in the Cybernet.

When a player gains a bonus counter, he places it in
front of him and can use it to purchase cards with costs.

If you are forced to discard a card with bonus
counters the bonus counters are not lost. Place them
in your control area. You may use them to pay costs on
other cards.

Start-of-turn markers

These markers are used to indicate that a once-per-
turn ability has been used.

When a player activates an ability with the once-
per-turn icon ( ) (p.25)(p.26), he must put a start-
of-turn marker on the ability to show that it has been
used.

During the beginning of turn phase ( ), the
player removes all start-of-turn markers from cards
under his control (p.08).

The various counters are designed to show information clearly to all
players.

This information might be control of a block, payment for a card, or use
of an ability.
