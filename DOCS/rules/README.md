# Structured rulesets

The rulebooks in `DOCS/Original/` are authoritative. These modules are concise,
implementable derived rules with stable IDs, source locators, applicability, and
engine maturity. Read the game landing page first:

- [Speedrunners](speedrunners.md) — base game.
- [Shadowraiders](shadowraiders.md) — expansion and modes; base-game rules still apply.

Use the entry format and status meanings in [documentation governance](../governance.md).
Tracked transcripts under [transcripts/](transcripts/) are searchable source
derivatives, not executable rules or replacements for the original PDFs.
