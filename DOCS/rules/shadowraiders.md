# Rules digest — Zaibatsu Shadowraiders (expansion)

This is the stable entry point for Shadowraiders. The expansion inherits the
Speedrunners base rules unless a Shadowraiders rule explicitly replaces them.
Its derived modules use stable `SH-` IDs with source locators and implementation
maturity; they do not replace the authoritative rulebook.
