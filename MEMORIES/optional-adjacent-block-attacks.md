---
title: Block attack choices precede their source roll
type: decision
---
Yakuza uses a typed optional adjacent-pawn choice before one skull rolls; preserve ordinary Delete's separate public-roll-then-assignment order. Physical neighbor blocks determine range; literal friendly/neutral pawns qualify. No pawn activation/cost/modifier is added. Clear the block choice before ordinary elimination opens a permitted defender response; never reroll that accepted attack. See [ADR-0022](../DOCS/adr/0022-optional-adjacent-block-attacks.md). Current source protocol/checksum is v20/block-bonus-counters; frozen regression stays unchanged.
