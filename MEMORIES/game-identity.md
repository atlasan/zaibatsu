Zaibatsu is a print-and-play cyberpunk board game by Froylan Rutiaga (art by
KoTdeSigN), CC BY-NC 2.5 MX. **Speedrunners** is the base game / core engine:
2–4 players are rival megacorporations laying hex "information blocks" to grow
the **Cybernet**, moving pawns with four abilities (Search / Delete / Reboot /
Icebreaker), drawing from a shared 54-card action deck; **win by placing all
your control markers**. **Shadowraiders** is an expansion adding threats,
mission cards + medals, stealth movement, Black ICE, mercenaries, and four game
modes (Shadowraiders, Chaos solo, Outbreak solo, Total War 2–8p).

Authoritative rule digests: `DOCS/rules/speedrunners.md` and
`DOCS/rules/shadowraiders.md` (distilled from the rulebook PDFs).
